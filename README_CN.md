## 功能特性

- **原生体验**: 使用 SwiftUI 构建，带来流畅且响应迅速的用户界面。

- **高级播放功能**:
  - 支持后台播放
  - 悬浮迷你播放器，支持快速控制
  - 播放队列管理（上一首/下一首）
- **歌词系统**: 支持精准的滚动歌词显示。
- **媒体库管理**:
  - 最近播放记录（自动去重）
  - 我的收藏系统
- **现代 UI 设计**:
  - 优雅的深色模式设计
  - 毛玻璃效果与流畅动画
  - 列表滑动操作支持

## 环境要求

- iOS 15.0+
- Xcode 14.0+
- Swift 5.0+

## 安装说明

1. 克隆本项目仓库。
2. 使用 Xcode 打开 `Xmusic.xcodeproj`。
3. 在模拟器或真机上编译运行。

## 使用指南

1. **搜索播放**: 搜索歌曲并即点即播。
2. **管理音乐**: 将喜欢的歌曲加入收藏，或查看最近播放历史。

## 开发结构

项目代码结构清晰：

- `Sources/`: 主要源代码目录。
  - `Views/`: SwiftUI 视图组件 (PlayerView, HomeView 等)
  - `Models/`: 数据模型 (SwiftData 实体)
  - `Services/`: 核心逻辑服务 (PlayerManager, MusicApiService 等)
  - `Resources/`: 图片资源等。
